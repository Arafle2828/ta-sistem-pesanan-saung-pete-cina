Design a modern, professional, responsive web application UI/UX mockup for a restaurant information system called “Saung Pete Cina”.

The system is a web-based restaurant ordering and management system with three core functions:

Menu ordering using QR Code
Real-time order monitoring
Sales reports and analytics

The design should feel like a modern Indonesian restaurant digital system, not just a restaurant landing page. The interface must prioritize usability, clarity, and efficiency for customers, employees, and restaurant owners.

Visual Identity

Use a Modern Earthy Restaurant visual style inspired by Indonesian food and natural materials.

Primary color palette:

Dark Green: #2F5D50
Deep Green: #23463D
Wood Brown: #8B5E3C
Light Beige: #F7F3EA
White: #FFFFFF
Soft Green: #7A9E7E
Success Green: #3F8F5F
Warning Gold: #D9A441
Danger Red: #C94C4C
Dark Text: #252525

The overall appearance should be clean, elegant, warm, modern, and professional.

Avoid excessive traditional ornaments, excessive gradients, overly decorative elements, or a generic corporate SaaS appearance.

Use:

Rounded cards
Subtle shadows
Clean spacing
Modern typography
Clear visual hierarchy
High-quality Indonesian food imagery
Simple line-style icons
Responsive layouts
Accessible contrast
Typography

Use a modern sans-serif font such as Inter, Plus Jakarta Sans, or Poppins.

Headings should be bold and easy to scan.
Body text should be clean and highly readable.

Design Requirements

Create a consistent design system across all pages.

The UI should look like a real production-ready restaurant management system, suitable for a university final project / D3 Information Systems project.

Prioritize:

usability
responsive design
clear information hierarchy
simple navigation
efficient restaurant workflows
real-time order visibility
readable sales analytics

Show both customer-facing mobile screens and employee/admin desktop dashboard screens.

The final mockup should demonstrate how QR Code ordering, real-time order monitoring, and sales reporting are integrated into one coherent web application.

Do not make it look like an online food delivery marketplace such as GoFood or GrabFood. This is an in-restaurant ordering and management system for Saung Pete Cina.

Use realistic Indonesian menu examples and Indonesian Rupiah (Rp) pricing.

Overall style keywords:

Modern Indonesian Restaurant + Earthy + Clean + Professional + Warm + Minimal + Responsive + Restaurant Management System + QR Ordering + Real-Time Monitoring + Sales Analytics
