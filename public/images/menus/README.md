# Direktori Gambar Menu Lokal (`public/images/menus`)

Taruh file foto menu Anda (format `.jpg`, `.jpeg`, `.png`, atau `.webp`) di dalam folder ini.

## Contoh Penamaan & Penggunaan URL
Jika Anda menyimpan file di:
`d:\Projek_TA\public\images\menus\ayam-taliwang.jpg`

Maka URL gambar yang dimasukkan ke **Manajemen Menu** atau **Database (`image_url`)** cukup ditulis:
```text
/images/menus/ayam-taliwang.jpg
```
